# Food Ordering App 🍔🍕🥗

A modern food ordering web application built using React, Redux Toolkit, Parcel, and Tailwind CSS.

## 🚀 Live Demo

https://rohitsaini0444.github.io/food-ordering-app/

---

## ✨ Features

- Browse restaurants and food items
- Search restaurants
- Add to cart functionality
- State management using Redux Toolkit
- Responsive UI
- Dynamic routing with React Router
- Styled using Tailwind CSS
- Unit testing with Jest & React Testing Library

---

## 🛠 Tech Stack

- React
- React Router DOM
- Redux Toolkit
- Tailwind CSS
- Parcel Bundler
- Jest
- React Testing Library

---

## 📂 Project Setup

### Clone the repository

```bash
git clone https://github.com/Rohitsaini0444/food-ordering-app.git
```

### Move into project folder

```bash
cd food-ordering-app
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm start
```

---

## 📦 Build for Production

```bash
npm run build
```

---

## 🚀 Deployment

The project is deployed using GitHub Pages.

### Deploy Command

```bash
npm run deploy
```
